# valoon-chat

Valoon Chat is an enterprise messaging platform for Microsoft Teams and
standalone web. This public profile is the entry point for visitors to the
organization on GitHub.

## What you'll find here

- **Clients**: Vue/Quasar front-ends — `ui`, `admin-ui`, and integration surfaces.
- **Services**: backend micro-services in Go, .NET, Python, and Node —
  analytics, entity, feature-flags, media, notifications, reports, translation,
  weather, and more.
- **Bots**: messaging-platform adapters — Teams, Telegram, Viber, WhatsApp,
  plus a central `bot-proxy`.
- **Gateway**: the Go edge service that fronts the platform.
